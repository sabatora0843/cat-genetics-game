# Cat Coat Genetics Quiz v5

静的HTML + CSS + JavaScriptで動作する猫の毛色遺伝クイズです。

## 仕様

- 設問時に W O A B C D I S T L の遺伝子型を表示
- 優性形質は `W-`, `A-`, `S-` のように表示
- 劣性ホモは `ww`, `aa`, `ss` のように表示
- `-` は、もう一方のアレルがどちらでも表現型が変わらないことを示す
- 回答後に正解と判定理由を表示

例:
- 白一色の主要条件: `W-`
- 黒ブチの主要条件: `ww oo aa S-`
- キジ系の主要条件: `ww oo A- ss`

実際の猫の毛色遺伝を簡略化した教材・ゲーム用モデルです。
